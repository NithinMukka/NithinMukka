### 🏆 Featured Projects

These three repositories showcase my work in asynchronous system design, browser extensions, and full-stack integration with third-party payment gateways.

#### 1. ⚙️ [movie-api](https://github.com/NithinMukka/Movie-API)
An asynchronous backend API powering movie booking, schedules, and payment processing.
* **Tech Stack:** `Python` · `FastAPI` · `SQLAlchemy 2.0 (asyncpg)` · `Pydantic v2` · `PostgreSQL 16` · `Redis` · `Razorpay` · `Alembic` · `Docker`
* **Key Features:** Features fully async database interactions via SQLAlchemy, Redis-based caching for low latency, database migrations via Alembic, and secure Razorpay payment webhook verification. Fully containerized.

#### 2. 🎬 [movie-booking-ui](https://github.com/NithinMukka/movie-booking-ui)
The interactive frontend web interface optimized for seat selection and ticket purchase.
* **Tech Stack:** `Next.js 16 (App Router, RSC)` · `React 19` · `TypeScript 5` · `Tailwind CSS` · `Razorpay Checkout JS`
* **Key Features:** Employs React Server Components (RSC) for optimized initial loading states and SEO performance, using Tailwind for styling and Razorpay Checkout SDK for client-side payment handling.

#### 3. 🧩 [student-buddy](https://github.com/NithinMukka/student-buddy)
A productivity-oriented Chrome extension helper built to assist students with quick access to timetables and workflow utilities.
* **Tech Stack:** `HTML` · `CSS` · `JavaScript` (Chrome Extension APIs)
* **Key Features:** Utilizes the Chrome local storage and runtime APIs to manage user data efficiently directly inside the browser, providing quick access to notes, tasks, and routine lists.
